# ICU Handover Hub

Please create a new handover app for the intensive care unit at Salisbury District Hospital. The aim of the app is to keep track of the current patients admitted to ICU with information about key aspects of their past medical history, current admission, current management, key investigation findings and outstanding tasks. Please allow the recording of whether a treatment escalation plan is in place and the details of this. Please allow the recording of whether a decision has been made not to attempt CPR. Please allow me to document the patients' next of kin and the last time this person was updated/spoken to. Please allow me to record key patients on outlying wards e.g. Patients referred to critical care who may require admission at some point. Please Allow me to change the status of patients entered in the app (e.g. Admitted, discharged (including discharge destination), died). Please save records within the app so that they can be reviewed even when a patient has been discharged. Please make all entries editable. Please make all data within the app encrypted from end to end (data security and robust information governance are of primary importance in the building of this app). In the key investigations tab please save all investigations entered but allow users to view 'most recent blood results', 'most recent CXR', 'most recent CT chest' etc. Please make the app only accessible by username and password so that no information can be accessed unless logged in. I would like the app to be able to interact/interface with another app I have created (https://lovable.dev/projects/a8eeeba1-1944-4344-93c0-4f9de4184412).
